## 快捷键逐项保留

- ⌘K（Windows/Linux Ctrl+K）：命令中心。Mac Ctrl+K 是终端 readline，不拦截。
- ⌘J / Ctrl+J：笔记 dock；在全部笔记页面不切换隐藏 dock。
- ⌘. / Ctrl+.：快捷指令，打开后 1–9 选择；保留 IME 和触摸条件。
- ⌘N（PWA）/ ⌥N：现有新终端快速路径，不因“统一新建菜单”改为普通对话。
- ⌘1–9 / Ctrl+1–9：切换会话。⌘R / Ctrl+R：当前会话重命名，非会话页不抢刷新。
- ⌘W（PWA）/ ⌥W：会话归档/终端关闭，不仅是关页面；保留确认、取消后焦点与关闭语义。
- ⌘[ / Alt+←：返回；不吞普通输入/终端需要的按键。
- Enter/Shift+Enter、排队/steer 快捷操作仍复用 AgentInput 原实现，不由原型重新定义。

## 团队 UI 不得被瘦身掉的内容

真实 TeamsScreen 包括团队列表、创建/启动、机器不可用状态、准备/失败、负责人对话入口、
目标与任务树、成员/负责人会话、定时安排（schedules）、设置与归档限制。侧栏还包括团队
展开后的成员和历史会话。新视觉必须承接这套状态；当前三角色展示不足以替代真实团队 UI。
接入前需逐一验证团队采用 fromSession、角色、任务/目标更新、调度、失败恢复和归档 blocker。

## 结论

导航可以减到新建、搜索与命令、团队、待办、帮助；设置/笔记/主题放底部。
终端收进新建，运行概览收进命令中心和会话工具。视觉不构成删除数据或重写快捷键的理由。
本轮完成入口设计盘点并补原型关键入口；所有「待迁移」项必须在真实 UI 上线前完成，不标记已验收。

本轮浏览器实测：新建七个选项可见；⌘K 打开命令中心并搜索“文件”，可进入示例文件预览；⌘J 打开笔记并输入；⌘. 打开快捷指令。390px 笔记实际字号 17px、页面横向溢出 0。上述都是原型交互验证，不代表远端文件、tmux、团队或笔记同步已验收。

第五轮补充：仅保留侧栏底部主题切换；列表视图按钮提供项目/标签/不分组，原型可编辑单标签，拖拽不分组列表排序，菜单提供上移。正式版仍须保留已有多标签模型、手动排序持久化、状态/归档筛选与团队分组约束，原型单标签不覆盖真实数据结构。
更新提醒与 changelog 弹窗新增本地预览：关闭不标记已读，显式确认才变成“更新记录”；历史入口可达。正式版继续用 ChangelogNotice 的跨版本未读计算、CLI 版本提示、安装命令与 seen 存储语义；不把原型演示当真实 SW 接管或 CLI 升级。

第六轮：文件目录/多文件预览、改动、快捷笔记、全部笔记、运行概览、浏览器示意迁入统一右侧标签区。
长内容保留标签上下文；短事务仍用模态。桌面并排，≤1100px 全屏返回。单实例激活复用、文件按路径区分，切换与收起保留挂载状态；笔记草稿在父级保存。
生产接入待项仍包括远端文件/端口、浏览器嵌入限制、真实同步与按 session/workspace 隔离。

第六轮浏览器验证：1440px 三栏下对话宽 681.6px、工作区宽 518.4px、四个标签，页面溢出 0；文件与笔记切换、收起后重新打开均保留笔记草稿；键盘右箭头切换激活标签。320px coarse 工作区全屏宽 320px、溢出 0，关闭最后标签返回会话。类型检查与构建通过。

第七轮：右栏去掉独立标题，保留单排标签及操作；relay/机器移入会话顶栏。新增界面状态页，可切换启动、路由加载、空会话、失败、连接恢复、权限等待。
额外设计盘点：更新提醒/历史、复制提示、长内容滚动、权限确认、连接失败、首次无数据、移动全屏返回都已有设计位置；真实首屏仍涉及 index.html 预绘制、RouteLoading 与 prepaintSplash 安全移除链路，正式接入需一起验证，当前只设计不改这些运行机制。

第七轮浏览器验证：桌面无重复工作区标题/会话元信息行，机器和 relay 位于顶栏；320px coarse 顶栏标题可用宽约 77px、页面无横向溢出。六种状态可切换，失败重试返回空会话；减少动态效果时活动条动画关闭。类型检查与构建通过。以上为本地原型验证。

第八轮：Owner 明确 loading 指整屏启动品牌动画；修订为静止微笑终端中心、Agent/终端/工作空间四端连接与轻脉冲，替代第七轮过于通用的细活动条。明暗主题及 320px coarse 预览无溢出，减少动画时信号静止；六状态与失败重试仍通过。终端、右键和拖拽规则已进 design-language；新增右键/终端交互尚未实现，正式启动链路也未替换。

手机登录修复（本地未发布）：直接修改真实 /login 样式，表单可放下时双向居中；超高自动外边距归零保持顶部可达，键盘态解除 100dvh 最小高度约束。手机首次不自动聚焦，保留验证码步骤聚焦；手机/矮横屏简化外层卡片并显示品牌。390×844、320×568、844×390、1280×900 两主题浏览器验证，适屏居中偏差 0、横向溢出 0，展开密码后页尾可滚动可达，模拟 340px 键盘视口有效。Auth 19 测试通过，两个关键 CSS 变异均被测试捕获；真机键盘/IME 验收补入 V-080。
