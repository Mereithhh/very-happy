# Code of conduct

We want collaboration here to be technically rigorous, welcoming, and safe.

## Expected behavior

- Be respectful, specific, and patient with contributors of different experience.
- Critique code and decisions, not people.
- Give reproducible evidence; acknowledge uncertainty and correct mistakes.
- Protect privacy. Redact credentials, personal data, session content, and private
  infrastructure details before posting.
- Respect maintainers' decisions about scope, safety, compatibility, and release
  timing, even when you disagree.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, doxxing,
deliberate disclosure of secrets or vulnerabilities, spam, and sustained bad-faith
disruption are not acceptable in project spaces or when representing the project.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile
or the repository's private security-reporting channel when sensitive information
is involved. Maintainers may edit or remove content, lock discussions, reject
contributions, or temporarily/permanently restrict participation. Reports will be
handled as confidentially as practical, with conflicts of interest avoided.
